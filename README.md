# Student Manager

A simple **C# console application** to manage students, their roll numbers, and grades. This project allows you to **add, view, search, update, sort, and filter students**, and saves data in an **XML file** for persistence.

---

## Features

- Add new students with **automatic unique IDs**.
- View all registered students.
- Search students by:
  - **ID**
  - **Roll Number**
  - **Name** (partial match)
- Update a student's **grade**.
- Sort students by:
  - Name
  - Grade
  - Roll Number
- Filter students by **name and grade**.
- Data persistence using **XML serialization**.

---

## Technologies

- **C#** (.NET 6 or higher recommended)
- **Console Application**
- **XML Serialization** for data storage
